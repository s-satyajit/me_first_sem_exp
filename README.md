## 🚀 How to run / view

1. Clone the repo:

```bash
git clone https://github.com/s-satyajit/me_first_sem_exp.git
cd me_first_sem_exp
```

2. For Python codes:

* **Running a `.py` file directly:**

```bash
python filename.py
```

* **Running notebooks:**

```bash
# create virtual environment (recommended)
python -m venv venv
# activate (Windows)
.\venv\Scripts\activate
# activate (Linux/Mac)
source venv/bin/activate

# install dependencies if you maintain a requirements file
pip install -r requirements.txt

# launch Jupyter
jupyter notebook
```

3. For C++ codes:

```bash
# compile the file
g++ filename.cpp -o output

# run the compiled file
./output
```

> If a folder contains `.ipynb` files, open them in Jupyter. If you see `.cpp` or `.vb` files, compile/run them with the appropriate compiler or IDE.
